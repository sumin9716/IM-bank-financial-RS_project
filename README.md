# iM뱅크 법인 고객 데이터 기반 영업점 후보 지역 추천

iM뱅크 법인(B2B) 고객 데이터를 시군구 단위로 집계하고, 법인 자금 규모가 큰 지역과 특성이 비슷한 시군구를 영업점 후보로 순위를 매기는 분석 노트북입니다. 코사인 유사도 점수와 규칙 기반 점수를 합쳐 최종 점수를 만들고, 특정 시군구와 비슷한 지역을 스케일러별로 비교합니다.

Day1~Day5 학습 노트에서 다룬 전처리, 콘텐츠 기반 유사도, 추천 평가지표를 하나의 분석 흐름으로 묶은 노트북입니다.

## 분석 흐름

노트북: [`notebooks/branch_recommendation.ipynb`](notebooks/branch_recommendation.ipynb)

1. 최신 기준년월(202412)의 법인 고객 행을 시군구별로 집계하고 총예금, 총여신, 거래 채널 비중, 여신비율, 평균 등급, 전담고객비율 같은 파생 지표를 만듭니다.
2. 시중은행 점포 위치 데이터로 시군구별 점포 수, 은행 수, 법인 고객 1곳당 점포 수를 더합니다.
3. 11개 피처를 MinMaxScaler로 맞춘 뒤, 총자금수요(총예금 + 총여신) 상위 20% 지역의 평균 벡터와 각 지역의 코사인 유사도를 구합니다.
4. 7개 지표의 고정 가중합인 규칙 점수와 합쳐 `최종점수 = 0.9 × 유사도점수 + 0.1 × 규칙점수`를 계산하고, 수도권(서울·경기·인천) 시군구의 순위를 매깁니다.
5. 수도권 총자금수요 상위 10개를 기준 정답으로 삼아 Precision@10, Recall@10, Hit Rate@10, NDCG@10을 계산합니다.
6. 입력한 시군구와 특징 벡터가 비슷한 지역을 스케일러 6종(MinMax, Standard, Robust, MaxAbs, Quantile, Yeo-Johnson)별로 비교합니다.

## 한계

- 평가가 순환 구조입니다. 기준 정답을 정한 총자금수요가 레퍼런스 지역 선정과 특징 벡터(`log_총자금수요`)에도 쓰이므로, 위 지표는 점수가 총자금수요 순위와 얼마나 맞는지를 보여 줄 뿐 실제 영업점 성과를 예측하는 능력을 검증하지 않습니다.
- 규칙 점수 가중치(`rule_weights`)는 노트북에 고정값으로 들어 있습니다. 같은 노트북의 랜덤 포레스트 중요도 출력과 비교하면 규칙 점수에 쓰는 7개 피처의 순위는 같지만 값은 다르며, 고정값을 정한 과정은 남아 있지 않습니다.
- 최신 한 달(202412)의 스냅샷만 쓰므로 시간에 따른 변화는 반영하지 않습니다.
- iM뱅크의 기존 법인 고객만 집계하므로, 다른 은행과 거래하는 잠재 고객 수요는 경쟁 강도 피처(시중은행 점포 수)로 간접적으로만 반영됩니다.
- 원천 데이터가 저장소에 없어 저장된 출력을 그대로 재현할 수 없습니다.

## 실행 방법

원래 실행 환경은 Python 3.9.6이고, 테스트는 Python 3.11에서 확인했습니다.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab notebooks/branch_recommendation.ipynb
```

- 실행하려면 `data/`에 CSV 파일 두 개가 있어야 합니다. 파일 이름, 인코딩, 컬럼은 [`data/README.md`](data/README.md)에 정리했습니다.
- 그래프의 한글은 macOS에서 AppleGothic, Windows에서 Malgun Gothic, 그 밖의 OS에서 NanumGothic으로 표시합니다. Linux에서는 나눔고딕 폰트를 설치해야 합니다.

## 테스트

원천 데이터 없이 돌아가는 테스트입니다. 노트북의 함수 정의(구간 문자열 변환, 평가 지표)를 직접 검사하고, 같은 컬럼 형식의 합성 데이터로 노트북 사본을 임시 폴더에서 끝까지 실행합니다.

```bash
pip install -r requirements-dev.txt
python -m pytest
```

## 유지보수 메모

- 노트북에 저장된 출력은 원천 데이터로 실행한 결과의 유일한 기록입니다. 원천 데이터 없이 실행하거나 합성 데이터로 실행한 출력은 커밋하지 않습니다.
